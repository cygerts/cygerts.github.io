# AI Safety Group at NASK Website

Simple GitHub Pages website for a research group.

## Site Structure

- Home: `index.md`
- People: `people.md`
- Publications: `publications.md`
- Blog: `blog.html`, posts in `_posts/` (optional `external_url` and `external_label` add a cross-post link)
- Funding: `funding.md`
- News: `news.md`

## How To Edit

1. Open the page file you want to update.
2. Edit Markdown content.
3. Commit and push to `main`.

## Deployment

This site uses Jekyll with the `minima` theme and deploys on GitHub Pages from the `main` branch.
